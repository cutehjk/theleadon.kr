관리자 연결

GitHub '접근 키(토큰)'를 붙여 넣으면 글을 쓸 수 있습니다. 처음 한 번만 하면 됩니다.

접근 키 만드는 방법
  1. GitHub(cutehjk 계정)에 로그인한 상태에서 새 접근 키 만들기 화면을 엽니다.
  2. Token name: 홈페이지 소식 관리처럼 알아보기 쉬운 이름을 적습니다.
  3. Expiration(만료일): 원하는 기간을 고릅니다. 만료되면 같은 방법으로 새로 만들면 됩니다.
  4. Repository access: Only select repositories를 고르고 cutehjk/theleadon.kr를 선택합니다.
  5. Permissions → Repository permissions → Contents를 Read and write로 바꿉니다.
  6. 맨 아래 Generate token을 누르고, 나온 키를 복사해 위 칸에 붙여 넣습니다. (키는 다시 볼 수 없으니 이 화면에서 바로 붙여 넣으세요)
