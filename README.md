# theleadon.kr

## 소식 게시판 글 올리기 (관리자 화면)

**https://theleadon.kr/admin.html** 에서 글을 쓰고, 고치고, 지웁니다. 메뉴에는 나오지 않는 주소이니 즐겨찾기해 두세요.

1. 처음 한 번만: 관리자 화면의 '접근 키 만드는 방법'을 따라 GitHub 접근 키를 만들어 붙여 넣습니다.
2. 게시판(공지·보도자료·사업소식·뉴스레터)을 고르고 [+ 글쓰기]를 누릅니다.
3. 제목·날짜·본문을 쓰고 사진·첨부파일을 고릅니다. 사진은 자동으로 가로 1600px로 줄여서 올라갑니다.
4. [미리보기]로 확인한 뒤 [등록]을 누르면 1~2분 뒤 홈페이지에 나타납니다.

- 연결한 컴퓨터에서는 소식 페이지에 [+ 글쓰기]·[글 관리], 글 화면에 [수정] 버튼이 보입니다. 다른 방문자에게는 보이지 않습니다.
- 접근 키가 만료되면 같은 방법으로 새로 만들어 다시 연결합니다.
- 공용 PC에서는 '이 컴퓨터에 기억하기'를 해제하거나 쓴 뒤 [연결 해제]를 누르세요.

## 화면 동작

- 상단 메뉴의 '소식'은 항상 보입니다. 글이 0건이면 홈의 소식 섹션과 푸터의 '소식' 링크는 숨겨지고, 홈에는 '주요 사업 영역'이 그대로 보입니다.
- 글이 1건 이상이면 홈의 '주요 사업 영역' 자리에 최근 소식 3건이 표시됩니다.
- 뉴스레터는 소식과 따로 상단 메뉴 '뉴스레터'(newsletter.html)에 호수(Vol.) 순으로 쌓이고, 홈에는 최신호 띠 하나만 보입니다. 호수는 글쓰기 화면에서 다음 번호가 자동으로 들어갑니다.

## (참고) posts.json 직접 고치기

관리자 화면이 아래 형식으로 저장합니다. 직접 고칠 때는 형식이 깨지지 않게 주의하세요.

```json
[
  {
    "id": "20261020-1",
    "title": "글 제목",
    "category": "news",
    "date": "2026-10-20",
    "pinned": false,
    "cover": "news/images/20261020-1.jpg",
    "coverAlt": "사진 설명",
    "body": "첫 문단입니다.\n\n빈 줄(\\n\\n)로 문단을 나눕니다.",
    "images": [{ "src": "news/images/20261020-1-2.jpg", "alt": "본문 사진 설명" }],
    "attachments": [{ "name": "안내문.pdf", "href": "news/files/안내문.pdf", "size": "PDF · 320KB" }]
  }
]
```

| 항목 | 필수 | 설명 |
|---|---|---|
| `id` | ✅ | 글 주소에 쓰입니다. 겹치지 않게 `날짜-번호` 형식을 권장합니다 → `news-view.html?id=20261020-1` |
| `title` | ✅ | 제목 |
| `category` | ✅ | `notice`(공지) / `press`(보도자료) / `news`(사업소식) / `newsletter`(뉴스레터) |
| `vol` | 뉴스레터면 ✅ | 뉴스레터 호수 (숫자) |
| `sections` | | 뉴스레터 기사 목록. `[{ "title": "📮 국내 뉴스", "image": "...", "imageAlt": "...", "items": [{ "title": "기사 제목", "url": "https://...", "source": "출처 · 날짜" }] }]` |
| `outro` | | 뉴스레터 맺음말 (기사 목록 아래) |
| `date` | ✅ | `YYYY-MM-DD`. 최신순으로 정렬되고, 7일 이내면 NEW 표시 |
| `pinned` | | `true`면 목록 맨 위 고정 띠에 표시 (최대 3건) |
| `cover` | | 대표 사진. 16:9로 잘려 보이므로 가로 사진, 가로 1200px 이상 권장. 없으면 기본 이미지 |
| `coverAlt` | 사진이 있으면 ✅ | 사진 설명 (시각장애인 접근성·검색에 필요) |
| `body` | | 본문. 글자 그대로 표시되며 HTML은 쓸 수 없습니다 |
| `link` | | 원문 주소(보도자료 기사 등). 글 아래 [원문 기사 보기] 버튼으로 표시 |
| `images` | | 본문 아래에 들어갈 추가 사진 |
| `attachments` | | 첨부파일 |
| `draft` | | `true`면 화면에 표시하지 않음 (임시저장) |

- 사진은 `news/images/`, 첨부파일은 `news/files/`에 올립니다.
- 글과 글 사이에는 쉼표(`,`)가 필요합니다. 쉼표나 따옴표가 빠지면 파일 전체를 읽지 못해 소식이 모두 숨겨집니다. 저장 전에 https://jsonlint.com 에서 확인하면 안전합니다.
